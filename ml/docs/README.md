# WeatherFusion ML Dataset Documentation

This directory contains annotation guidelines and documentation for
WeatherFusion India's optional AI/ML work.

The repository includes a documented evaluation of a historical NOAA narrative
event-type baseline. Its scope, reproducibility constraints, and limitations
are recorded in [NOAA_STORM_EVENTS_DATASET.md](NOAA_STORM_EVENTS_DATASET.md).
It is not a citizen-report truthfulness or duplicate-detection model.

Raw datasets, generated splits, and model outputs are intentionally ignored by
Git. Recreate them locally from approved sources; do not commit them to the
repository.
